Welcome to FoxBox

FoxBox is Auburn Academy's bespoke file service for sharing files with members of the Academy community.



Using FoxBox

Sharing files with FoxBox is available to Auburn Academy students and staff. For more information on getting started with FoxBox, please contact the Office of Information Technology.


Files shared through FoxBox are accessible via direct links. While some files are available to the general public, others will prompt users to first log in using their Auburn Academy network credentials.
